# Вариант 43 — Матрица прав (операция × роль)

Операции: Просмотр запросов помощи, Создать/Редактировать/Удалить HelpRequest, Просмотр профилей волонтёров, Отклик на запрос, Назначение волонтёра, Управление категориями, Управление пользователями, Модерация отзывов.

Роли: Администратор, Пользователь (нуждающийся), Волонтёр

Таблица (кто может что)

- Просмотр запросов помощи: Администратор, Волонтёр, Пользователь (свои)
- Создать HelpRequest: Пользователь
- Редактировать HelpRequest: Пользователь (свой), Администратор
- Удалить HelpRequest: Пользователь (свой, если не assigned), Администратор
- Просмотр профилей волонтёров: Администратор, Пользователь, Волонтёр
- Создать VolunteerProfile: Администратор
- Отклик на запрос (создать Assignment): Волонтёр
- Назначение волонтёра: Администратор
- Изменение статуса Assignment: Волонтёр (назначенный), Администратор
- Создать Category: Администратор
- Редактировать/Удалить Category: Администратор
- Создать Review: Пользователь (для своих completed запросов)
- Модерация Reviews: Администратор
- Управление пользователями: Администратор
- Просмотр статистики: Администратор, Волонтёр (своей)

Примечания:

- По умолчанию пользователь видит только свои запросы помощи.
- Волонтёр видит все активные запросы помощи в системе (или по локации).
- Некоторые операции (например, удаление запроса) могут быть ограничены после назначения волонтёра.
