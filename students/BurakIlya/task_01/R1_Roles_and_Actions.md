# Вариант 43 — Волонтёры «Помощь рядом» — Роли и действия

Краткое описание

MVP: HelpRequest, Category, VolunteerProfile, Assignment, Review, User, Location. UI отображает список запросов помощи, возможность откликнуться волонтёру, чат (заглушка), отзывы; API: /requests, /categories, /volunteers, /assignments, /reviews. Приёмка (MVP): создание запроса помощи, поиск запросов, назначение волонтёра.

Роли и основные действия

- Администратор
  - CRUD для пользователей
  - CRUD для категорий помощи (Category)
  - CRUD для профилей волонтёров (VolunteerProfile)
  - Назначение волонтёров на запросы
  - Модерация запросов и отзывов
  - Просмотр всех данных и статистики

- Пользователь (нуждающийся в помощи)
  - Создание запросов помощи (HelpRequest)
  - Просмотр своих запросов и статусов
  - Общение с волонтёром через чат (заглушка)
  - Оставление отзывов (Review) после завершения помощи
  - Просмотр профилей волонтёров

- Волонтёр
  - Просмотр доступных запросов помощи
  - Фильтрация запросов по категории и локации
  - Отклик на запрос помощи
  - Изменение статуса выполнения задания
  - Общение с пользователем через чат (заглушка)
  - Просмотр своего профиля и рейтинга

Примеры сценариев

- Пользователь создаёт запрос помощи с категорией "Доставка продуктов" → волонтёр видит запрос на карте (бонус) → откликается → система создаёт Assignment → статус запроса меняется на "assigned".
- Волонтёр завершает помощь → пользователь получает уведомление → оставляет Review с оценкой → рейтинг волонтёра обновляется.
