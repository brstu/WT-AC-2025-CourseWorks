# Frontend — Оффер где? 📮

SPA-приложение для трекинга откликов на вакансии.

## Технологии

- React 18 + TypeScript
- Vite (сборка)
- react-router-dom (маршрутизация)
- react-hook-form + zod (формы и валидация)
- CSS (без фреймворков)

## Установка и запуск

```bash
# Из корня проекта
npm install
npm run dev:frontend
```

Frontend доступен по адресу: http://localhost:5173

> **Важно**: Перед запуском фронтенда убедитесь, что бэкенд запущен (`npm run dev:backend`)

## Тестовые пользователи

## Структура страниц

### Публичные

- `/login` — Вход
- `/register` — Регистрация

### Защищённые (требуют авторизации)

- `/` — Канбан-доска (главная)
- `/companies` — Список компаний
- `/jobs` — Список вакансий
- `/jobs/:id` — Детали вакансии (этапы, заметки, напоминания)
- `/reminders` — Все напоминания
- `/users` — Управление пользователями (только для admin)

## Сценарии демонстрации

### 1. Регистрация и вход

1. Откройте http://localhost:5173
2. Перейдите на страницу регистрации
3. Введите email, пароль (мин. 8 символов, заглавная, строчная, цифра, спецсимвол)
4. После успешной регистрации вы будете перенаправлены на канбан

### 2. Создание вакансии

1. На главной (канбан) нажмите "+ Новая вакансия"
2. Заполните название, выберите компанию (опционально), укажите зарплату и ссылку
3. Вакансия появится на канбан-доске

### 3. Управление этапами

1. Откройте вакансию (клик по карточке на канбане или из списка)
2. В разделе "Этапы" добавьте новый этап (например: "HR-скрининг")
3. Этапы отображаются в хронологическом порядке

### 4. Добавление заметок

1. На странице вакансии в разделе "Заметки"
2. Введите текст заметки и нажмите "Добавить"
3. Заметки сохраняются с датой создания

### 5. Напоминания

1. На странице вакансии в разделе "Напоминания"
2. Введите текст и выберите дату/время
3. На странице `/reminders` можно видеть все напоминания с фильтрами

### 6. Административный функционал (admin)

1. Войдите как admin@example.com / Admin123!
2. В меню появится пункт "Пользователи"
3. Просмотр и удаление пользователей

## Особенности реализации

### Аутентификация

- Access token хранится в памяти (React Context)
- Refresh token хранится в httpOnly cookie
- Автоматическое обновление токена при 401 ошибке
- Автоматическое восстановление сессии при перезагрузке страницы

### Авторизация

- Защищённые роуты перенаправляют на `/login`
- Админ-роуты проверяют роль пользователя
- Владелец видит только свои данные

### UX

- Индикаторы загрузки на всех страницах
- Человекочитаемые сообщения об ошибках
- Подтверждение удаления
- Адаптивная вёрстка
