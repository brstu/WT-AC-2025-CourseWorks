# Фронтенд Freelance CRM

Веб-приложение на React + TypeScript для управления сделками фрилансера.

## Возможности

### ✨ MVP

- **Клиенты** - управление контактами клиентов
- **Сделки** - визуализация в виде воронки по этапам
- **Этапы** - управление этапами продажного цикла
- **Задачи** - доска задач с поддержкой статусов
- **Инвойсы** - управление счетами и отслеживание платежей
- **Дашборд** - аналитика и метрики

### 🎨 Компоненты

- **DealsPipeline** - Kanban-доска для сделок
- **TasksBoard** - Kanban-доска для задач со статусами
- **Dashboard** - главная страница с метриками
- **Формы** - создание и редактирование записей

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Предпросмотр build
npm run preview
```

## Переменные окружения

## API Интеграция

Фронтенд интегрируется с REST API бэкенда на Spring Boot.

### Основные эндпоинты:

- `GET /api/v1/clients` - список клиентов
- `GET /api/v1/deals` - список сделок
- `GET /api/v1/stages` - список этапов
- `GET /api/v1/tasks` - список задач
- `GET /api/v1/invoices` - список инвойсов

Все запросы требуют заголовок `Authorization: Bearer {token}`

## Работа с формами

### DealForm (Создание/редактирование сделки)

```
/deals/new           - создание сделки
/deals/:id           - редактирование сделки
```

Поля:
- Название (обязательное)
- Клиент (опционально)
- Этап (опционально)
- Сумма (опционально)
- Описание (опционально)

### InvoiceForm (Создание/редактирование инвойса)

```
/invoices/new        - создание инвойса
/invoices/:id        - редактирование инвойса
```

Поля:
- Номер инвойса (обязательное)
- Клиент (опционально)
- Сумма (обязательное)
- Статус (черновик/отправлен/оплачен)

## Дизайн

Приложение использует:
- **Цветовая схема**: темная тема с акцентами (бирюза/оранжевый)
- **Шрифт**: Inter/system fonts
- **Компоненты**: custom CSS (Glassmorphism)
- **Адаптивность**: grid/flexbox макеты

## Аутентификация

- Регистрация: `/auth/register`
- Вход: `/auth/login`
- Token хранится в localStorage
- Автоматическое добавление в заголовки запросов

## Скриптов для CI/CD

Команды npm:
- `dev` - запуск dev сервера
- `build` - production build
- `preview` - предпросмотр build
